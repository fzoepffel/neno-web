# Lexique data used by Neno

This is every fact the Neno app takes from **Lexique 3.83**, and nothing beyond it. It is
published so that anyone who receives the app can obtain the same data without the copy
protection an app store applies to a binary, and pass it on as the licence allows.

## What was changed

Lexique has 142,695 rows and 35 columns. This dataset is derived from ten of those
columns: ortho, lemme, cgram, genre, nombre, freqlemfilms2, freqlemlivres, freqfilms2,
freqlivres, infover.

1. The two lemma frequency columns were averaged per lemma.
2. The result was filtered to content words, function words being taught through grammar
   instead.
3. That list was sorted by frequency, and each word's position in it became the **rank**
   below. The rank is ours, not a Lexique column. It decides which words the app teaches
   and in what order.
4. Gender was resolved to one value per noun, by the more frequent form where Lexique
   lists both.
5. Verb forms were selected by their inflection tags and grouped into tables.
